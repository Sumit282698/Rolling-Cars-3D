# 🚗 Car Driving Simulator

An exciting 3D Android car game built completely from scratch using the open-source **Godot Engine**. Experience physics-driven driving directly on your mobile device, completely free!

## 📥 Download & Install

Get the latest build of the game directly onto your Android device:

👉 **[Download via Google Drive](https://drive.google.com/file/d/13qlczAlv4fYfjr4I1kXBap3PhWGy2hwr/view?usp=drive_link)**

### How to Install:
1. Click the download link above and download the `.apk` file.
2. Open the file on your Android device.
3. If prompted, allow installations from unknown sources in your device settings.
4. Install and start driving!
